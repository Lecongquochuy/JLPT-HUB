📲 Hướng Dẫn Cài Đặt App

🤖 Dành cho Android (Chrome / Edge):

  1. Nhấn nút "📲 Cài App" hoặc dấu 3 chấm (⋮) ở góc trên bên phải trình duyệt.
  2. Chọn "Cài đặt ứng dụng" (Install App).
  3. Hoặc đóng gói file .apk qua PWABuilder từ link GitHub Pages của bạn.

🍏 Dành cho iPhone / iPad (Safari):

  1. Mở trang web bằng Safari ➔ Nhấn nút Chia sẻ (Share ⬆️).
  2. Chọn "Thêm vào MH chính" (Add to Home Screen ➕) ➔ Nhấn Thêm.
